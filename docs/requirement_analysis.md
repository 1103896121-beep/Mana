# Mana (能量) —— 产品需求分析文档

> “生产力不是清单的堆砌，而是能量的流动。”

## 1. 项目背景与愿景 (Product Vision)
Mana 是一款专注于“能量管理”而非“清单堆砌”的高级效率工具。我们认为，每个人每天的精力（Mana）是有限的。Mana 试图通过魔法化、游戏化的视觉反馈，让用户在分配和消耗能量的过程中获得掌控感和愉悦感。

## 2. 核心特征 (Core Features)

### 2.1 能量驱动的任务系统 (Energy-Based Tasks)
- **Mana 值分配**: 每个任务不再仅仅是文字，而是一个消耗特定“能量值”的实体。
- **可视化消耗**: 随着任务的完成，用户的 Mana 值会发生动态变化，直观体现精力的产出。

### 2.2 具象化的气泡列表 (Bubble-Style List)
- **有序查阅**: 任务回归列表形式，确保在任务繁多时依然能直观地搜索与定位。
- **气泡元素**: 单个任务项采用“气泡/球体”视觉包裹，具备浮动感和软弹性质感，保留具象化的生命力。

### 2.3 动态能量流转 (Flow & Feedback)
- **实时反馈**: 通过 EnergySlider 和 Framer Motion 动效，用户能实时感知当前任务对其“总能量池”的影响。
- **沉浸式音效**: 配合操作提供空灵、纯净的反馈音效，增强“魔法”氛围。

### 2.4 极致极简主义 (Ethereal Minimalism)
- **去工具化**: 界面尽可能减少文字干扰，通过光影与色彩引导操作。
- **分享与共鸣**: 支持通过 ShareSummary 将当天的能量产出导出为精美的卡片。

## 3. 视觉语言 (Visual Language)
- **关键词**: 灵动、空灵、通透、秩序、魔法。
- **核心元素**:
    - **光晕 (Aura)**: 代表能量的散发。
    - **玻璃态 (Glassmorphism)**: 代表界面的通透与现代感。
    - **微动效 (Micro-animations)**: 代表任务的呼吸与存在。
- **色彩方案**: 蓝、靛、紫、白。

## 4. 目标用户 (Target Audience)
那些厌倦了传统、沉重效率工具，追求内心平衡、视觉审美且注重精力管理的创造者与职场人士（iOS 用户）。

## 5. 技术架构参考 (Technical Reference)
- **平台**: Web (Vite + React + TS), 针对 iOS 移动端优化。
- **核心组件**:
    - `TaskSphere`: 物理引擎容器。
    - `EnergySlider`: 能量调节组件。
    - `ShareSummary`: 导出模块。
- **动画**: Framer Motion / SVG Filter (Aura Effect)。
