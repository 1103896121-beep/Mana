# Mana (能量) —— 产品需求分析文档

> “生产力不是清单的堆砌，而是能量的流动。”

## 1. 项目背景与愿景 (Product Vision)
Mana 是一款专注于“能量管理”而非“清单堆砌”的高级效率工具。我们认为，每个人每天的精力（Mana）是有限的。Mana 试图通过魔法化、游戏化的视觉反馈，让用户在分配和消耗能量的过程中获得掌控感和愉悦感。

## 2. 核心特征 (Core Features)

### 2.1 时间驱动的任务系统 (Time-Based Tasks)
- **时间分配**: 每个任务设定消耗特定“所需时间（分钟）”，支持 1-300 分钟。
- **泡泡膨胀爆炸 (1.8s)**: 任务完成时，气泡经历 0.8s 膨胀动效 + 1.0s 粒子爆炸效果，节奏更紧凑、反馈更炫酷。
- **历史任务清理**: 提供“清除 7 天未完成任务”功能，保持任务列表的纯净与高效。

### 2.2 具象化的气泡列表 (Bubble-Style List)
- **极致视觉 (iOS 风格)**: 针对苹果用户习惯，精调亮/暗模式下的对比度与字体灰阶，使用更高品质的透明度与阴影方案。
- **增强时间戳**: 列表项显示完整的“年-月-日 时:分”，方便追踪长期任务。

### 2.3 动态提示与智能关怀
- **多维触发**: 基于累计数量、累计时长与完成频率实时监测。
- **温馨词库**: 系统随机抽取提示词，缓解压力。

### 2.4 灵活的管理与排序
- **多维排序**: 随时切换按创建时间或所需时长进行升/降序排列。
- **拖拽调整**: 支持实时拖拽改变优先级。

### 2.5 极致极简与双色模式 (Minimalism & Themes)
- **双色系支持**: 提供极致适配的亮/暗模式。
- **UI 增强**: 为 iOS 用户提供超大交互区域。

## 3. 技术架构与持久化
- **架构方案**: 无后端纯前端架构 (Serverless Frontend-Only)。
- **数据持久化**: 使用 `localStorage` 进行本地存储，支持基于日期的批量清理。
