# Mana (能量) —— 产品需求分析文档

> “生产力不是清单的堆砌，而是能量的流动。”

## 1. 项目背景与愿景 (Product Vision)
Mana 是一款专注于“能量管理”而非“清单堆砌”的高级效率工具。我们认为，每个人每天的精力（Mana）是有限的。Mana 试图通过魔法化、游戏化的视觉反馈，让用户在分配和消耗能量的过程中获得掌控感和愉悦感。

## 2. 核心特征 (Core Features)

### 2.1 时间驱动的任务系统 (Time-Based Tasks)
- **时间分配**: 每个任务不再是能量值，而是一个消耗特定“所需时间（分钟）”的实体，支持 1-300 分钟设定。
- **可视化进度**: 界面动态体现每日已消耗时间与剩余可用时间的对比。
- **泡泡膨胀爆炸**: 任务完成时，气泡将先经历 2-3s 的膨胀动效，随后伴随粒子爆炸销毁，模拟“压力释放”。

### 2.2 具象化的气泡列表 (Bubble-Style List)
- **有序查阅**: 任务回归列表形式，确保在任务繁多时依然能直观地搜索与定位。
- **气泡元素**: 单个任务项采用“气泡/球体”视觉包裹，具备浮动感和软弹性质感，保留具象化的生命力。

### 2.3 动态提示与智能关怀
- **实时反馈**: 通过视觉动效与空灵音效提供极致反馈。
- **智能提醒触发策略 (建议方案)**: 
    - **累计数量**: 每日任务完成数达到 5 个、10 个、15 个...（每 5 个触发一轮）。
    - **累计时长**: 每日任务总时长达到 120 分钟及后续每增加 120 分钟时触发。
    - **高频强度**: 30 分钟内连续释放 3 个及以上任务气泡时，识别为高压负载并触发休息建议。
- **关怀词库**: 系统从库中随机抽取提示词，防止话语重复枯燥。

### 2.4 灵活的管理与排序
- **多维排序**: 系统支持按“创建时间”或“所需时间”进行排序，且均支持顺序和倒序切换。
- **创建时间显示**: 列表项显示任务创建的具体时间点。
- **拖拽调整**: 用户可直接在列表中拖拽气泡实时改变优先级。

### 2.5 极致极简与双色模式 (Minimalism & Themes)
- **双色系支持**: 提供“亮色模式 (Light Mode)”与“暗色模式 (Dark Mode)”，适配用户不同场景下的视觉偏好。
- **UI 增强**: 为 iOS 用户提供更大的字体比例与更宽敞的交互区域，提升操作精度。

## 3. 视觉语言 (Visual Language)
- **关键词**: 灵动、空灵、平衡、双相。
- **核心元素**:
    - **光晕 (Aura)**: 代表能量的散发。
    - **玻璃态 (Glassmorphism)**: 代表界面的通透与现代感。
    - **微动效 (Micro-animations)**: 代表任务的呼吸与存在。
- **色彩方案**: 蓝、靛、紫、白（适配亮暗双色模式）。

## 4. 目标用户 (Target Audience)
那些厌倦了传统、沉重效率工具，追求内心平衡、视觉审美且注重精力管理的创造者与职场人士（iOS 用户）。

## 5. 技术架构与性能约束 (Technical Architecture)
- **架构方案**: **无后端纯前端架构 (Serverless Frontend-Only)**。系统完全运行在用户苹果手机本地浏览器或 PWA 环境中。
- **数据持久化**: 使用 `localStorage` 或 `IndexedDB` 进行任务数据的本地存储，确保离线状态下依然功能完备。
- **平台**: Web (Vite + React + TS), 深度适配 iOS 移动端 WebView 直触感。
- **核心组件**:
    - `TaskSphere`: 物理引擎容器。
    - `EnergySlider`: 能量调节组件。
    - `ShareSummary`: 导出模块。
- **动画**: Framer Motion / SVG Filter (Aura Effect)。
