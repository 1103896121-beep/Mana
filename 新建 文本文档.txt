太棒了！现在 **Mana 项目的代码工程、视觉资产、商业化策略已经 100% 打造完毕**。我们在代码层面已经不需要做任何修改了。

接下来，真正的战场将从代码转移到**苹果的开发者后台**。如果您想看到 Mana 出现在真正的苹果手机并开放给全世界下载，这就是接下来的完整路径指南：

### 第一步：开启苹果开发者身份 (💰准备阶段)
1. **注册开发者账号**：在浏览器搜索「Apple Developer Program」，使用您的 Apple ID 登录并支付年费（折合人民币约 688 元/年）。这是苹果的强制过路费。
2. **签署协议**：在后台填写您的身份证/企业信息和收款用银行卡（这是为了以后能收到别人打赏那 30 块钱的赞助费）。

### 第二步：建立 App 卡片 (✍️ 填表阶段)
1. 登录 **App Store Connect** (苹果的应用管理后台)。
2. 点击「新建 App」。
3. 把我们刚才写在 [APP_STORE_METADATA.md](cci:7://file:///e:/workrooten/Mana/APP_STORE_METADATA.md:0:0-0:0) 里的所有内容填进去：
   - 复制粘贴应用的**名称**、**副标题**、**描述文案**、**关键词**。
   - 填入我们在文档里写好的**价格** ($2.99)。
   - 在后台添加两个“消耗型内购项目 (Consumable)”，对应我们的“一杯咖啡”和“一顿午餐”，记下给出的两个 Product ID（只要和我们在代码里预设的 `com.david.mana.tip.coffee` 一样即可）。

### 第三步：生成最终安装包 (🖥️ 编译阶段，必须用 Mac)
*(由于您现在似乎是在用一台 Windows 电脑开发，这一步**必须**借用一台苹果电脑，或者在云端/虚拟机里租借运行 macOS 的环境)*

1. 在 Mac 电脑上，克隆您的这个 GitHub 代码仓库。
2. 确保 Mac 上安装了 **Xcode** (苹果官方编译软件，在 Mac App Store 免费下) 和 Node.js 环境。
3. 在代码目录的终端里，依次运行：
   - `npm install` (装依赖)
   - `npm run build` (打生产包)
   - `npx cap sync ios` (让原生壳子吃到最新的前端包)
   - `npx cap open ios` (这一步会自动唤起魔法——打开 Xcode 工程界面)

### 第四步：打包并上传给苹果 (🚀 发射阶段)
1. 在 Xcode 里，插上您的 iPhone 数据线（或者选 `Any iOS Device (arm64)`）。
2. 在 Xcode 顶部的菜单中，点击 `Product` -> `Archive`（归档）。
3. 等待电脑风扇狂转两分钟后，会弹出一个面板，点击 **Distribute App** (分发应用)。
4. 一路无脑点击 Next，这份精美的代码就会被打包成一个加密的 `.ipa` 文件，通过光缆直接传到苹果加州的服务器上了。

### 第五步：送审与庆祝 (🎉)
回到网页版的 App Store Connect，此时构建版本那里就会出现您刚才传上去的包。
选择它，点击**“提交以供审核”**。

快的话 24 小时内，慢的话两三天，您的邮箱就会收到一封让人心跳加速的邮件：**"Your app, Mana, is now Ready for Sale."**
